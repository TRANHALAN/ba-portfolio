Leave Request Process - BPMN 2.0
Business Process Model and Notation Diagram
Process Overview
Leave Request Flow: Complete workflow from submission to approval completion.
Process Steps
1. Employee Submission
Employee completes leave request form and submits for approval
2. Leader Review
Team leader reviews the request and either approves or rejects
3. Decision Gate
If rejected by leader, request ends. If approved, proceeds to HR
4. HR Processing
HR reviews leave balance and approves or rejects the request
5. Notification
Employee receives notification of final decision
6. Records Update
Approved leaves are recorded in the system
Key Points: ✓ Parallel decision points ✓ Approval workflow ✓ Notification system ✓ Data persistence
