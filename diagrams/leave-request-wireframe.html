WIREFRAME NOTES:
• This is a LOW-FIDELITY wireframe - no colors, icons, or gradients used
• All component boundaries are shown with borders to clarify structure
• Employee Information is pre-populated and read-only (display only)
• Leave Balance is highlighted to draw attention
• Form fields show input types (text, date, select, checkbox, textarea)
• File upload area uses dashed border to indicate drop zone
• Approval workflow shows 4-step process with visual timeline
• Action buttons are clearly separated at the bottom
• Layout is responsive and adapts to smaller screens
• Red asterisk (*) indicates required fields
• All placeholders use [brackets] to indicate content areas
